# Event Registration & Submission Platform

A full-stack web application built for managing event registrations and project submissions. It features role-based dashboards for participants and administrators.

## Tech Stack
- **Frontend Framework:** Next.js (App Router)
- **UI Library:** React
- **Styling:** Tailwind CSS
- **Backend/Database:** Supabase (PostgreSQL, Auth, Storage)

## Key Features
- **Participant Portal:** Secure registration, project submission form (screenshot upload, description, deploy link).
- **Admin Portal:** Comprehensive data grid to view, search, edit, and delete participant submissions, plus role management capabilities.
- **Secure Authentication:** Managed via Supabase Auth with automated role assignment.
